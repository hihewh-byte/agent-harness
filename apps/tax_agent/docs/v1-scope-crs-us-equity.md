## 0. 冻结声明

本文档定义 Tax Agent **第一版可交付范围**。超出边界的请求须明确降级为「不支持 / 需人工复核 / 列入 v2 backlog」，不得静默按错误规则计算。

## 1. 目标用户

| 维度 | v1 支持 | v1 不支持 |
|------|---------|-----------|
| 纳税人类型 | 自然人 | 企业、合伙企业、信托受益人复杂结构 |
| 居民身份 | 中国大陆**税务居民**（用户声明 + 问答确认） | 非居民、双重居民争议未澄清 |
| 收入属地 | 美国证券市场（美股）相关账户 | 港股/A股仅作 backlog；加密货币 |
| 申报动作 | 测算、材料清单、风险提示、建议草稿 | 电子税务局自动申报、代扣代缴义务人报送 |

---

## 2. CRS 语境下的产品定位

### 2.1 CRS 对用户的实际影响（产品需传达）

- 境外金融机构可能向中国税务机关交换账户与收入信息（Common Reporting Standard）。
- 用户**自行申报**境外所得仍是中国税务居民的法定义务；CRS 交换不等于「已报税」。
- Agent 价值：在用户上传券商材料后，将流水**结构化**为中国个税口径下的应税项目，并给出**可审计**的测算与申报准备清单。

### 2.2 v1 不做的 CRS 功能

- 不生成 FATCA/CRS 机构侧 XML。
- 不对接税务机关 CRS 反馈接口。
- 不判断用户是否会被「稽查」— 仅提示信息交换与资料一致性风险。

## 3. 收入类型范围（美股账户）

### 3.1 In Scope（P0）

| 代码 | 类型 | 典型来源字段 | 中国税目映射（v1） |
|------|------|--------------|-------------------|
| `DIVIDEND` | 现金分红 | Dividend, Payment | 利息、股息、红利所得（20%） |
| `CAPITAL_GAIN` | 卖出已实现损益 | Proceeds, Cost Basis, Realized P/L | 财产转让所得（20%） |
| `INTEREST` | 现金利息 / 货币基金收益 | Interest, Money Market | 利息所得（20%） |
| `WITHHOLDING_TAX` | 境外预扣税 | Tax Withheld, NRA Tax | 境外已纳税额（抵免输入） |
| `FEE` | 佣金 / 平台费 | Commission, Fee | 资本利得计税基础调整项 |

### 3.2 In Scope（P1）

| 代码 | 类型 | 备注 |
|------|------|------|
| `STOCK_COMPENSATION` | RSU/ESPP 等 | v1 草稿计税：归属 FMV / 出售增益（成本=归属日 FMV）；触发 R007 专家复核，输出草稿税额 |
| `FOREIGN_TAX_REFUND` | 退税调整 | 影响抵免追溯 |
| `FX_GAIN_LOSS` | 明确列示的汇兑损益 | 与交易损益拆分 |

### 3.3 Out of Scope（v1）

- 期权、期货、杠杆 ETF 的复杂税务处理
- 美国 K-1、合伙穿透
- 离岸公司持股架构
- 遗产、赠与、美国遗产税
- 州税（美国各州）独立申报

## 4. 输入材料范围

### 4.1 支持格式

- `xlsx`, `xls`, `csv`（券商年度对账单、交易明细、分红明细）
- 对话内**多文件**上传（同一 `sessionId` 合并为 `datasetId`）

### 4.2 券商模板（v1 优先覆盖）

| 优先级 | 券商/平台 | 模板 ID |
|--------|-----------|---------|
| P0 | Interactive Brokers (IBKR) | `broker_ibkr_v1` |
| P0 | Charles Schwab | `broker_schwab_v1` |
| P0 | Fidelity | `broker_fidelity_v1` |
| P1 | Tiger / 富途 / 长桥（美股子账户） | `broker_tiger_v1`, `broker_futu_v1` |
| P1 | Vanguard | `broker_vanguard_v1` |

未识别模板 → `template_unknown` + 半自动列映射 UI（对话澄清）+ **Medium** 风险。

### 4.3 必需用户声明（计算闸门）

计算引擎在以下字段未确认前**不得**输出最终税额（仅可输出草稿/区间）：

1. `taxYear` — 纳税年度（默认：最新已结束自然年）
2. `residentStatus` — `cn_tax_resident` | `non_resident` | `uncertain`
3. `fxPolicy` — 汇率口径（见计算规格）
4. `filingScope` — 仅境外所得 / 含境内综合所得。含境内时用户须在 `domesticIncome` 中申报工资薪金、劳务报酬、稿酬、特许权使用费及专项扣除；引擎按综合所得累进税率与境外分类所得**分别计税后合计**，不自动拉取境内个税 App 数据

## 5. 输出范围

### 5.1 必须输出

1. **结论摘要**：应税收入（人民币）、应纳税额、境外已扣税、可抵免限额、预计应补税额区间  
2. **分项明细**：按 `eventType` × `accountId` × `taxCategory`  
3. **计算依据**：规则版本 ID、公式步骤、引用的 `TaxEvent` ID 列表  
4. **申报材料清单**：个人所得税自行纳税申报表（B 表）相关附列资料提示（非正式表格代填）  
5. **风险提示**：缺失项、分类不确定项、CRS 一致性提示  
6. **免责声明**：非法律意见、非税务机关背书  

### 5.2 可选输出

- 假设场景对比（两种汇率口径 / 两种持有期认定）
- 机器可读 `auditBundle.json` 下载

---

## 6. 规则策略：最新规则自动更新

v1 采用 **VersionedRuleRepository**：

- 默认计算绑定 `latest_stable` 规则快照。
- 用户可显式指定 `ruleSnapshotId`（如「按 2024 年度口径重算」）。
- 法规更新后**不自动改写**历史报告；仅新计算使用新版本。

## 7. 对话能力边界

| 用户意图 | v1 行为 |
|----------|---------|
| 「帮我算 2024 年美股分红要交多少税」 | 标准计算流程 |
| 「给我申报需要准备的材料」 | 输出清单 + 已解析字段覆盖度 |
| 「德国房产租金怎么报税」 | 拒绝并指向 v2 国家插件 |
| 「我是不是不用报，CRS 会自动报」 | 教育性回答 + 免责声明，**不算税** |
| 「帮我直接提交电子税务局」 | 明确拒绝（非目标） |

---

## 8. 验收标准（场景级）

- [ ] 10 份脱敏 IBKR/Schwab 样例：关键字段 F1 ≥ 0.98  
- [ ] 5 份含分红 + 卖出 + 预扣税样例：与专家手工表差异 ≤ 1 RMB（确定性场景）  
- [ ] 100% 结果行可追溯到 `sourceEventIds`  
- [ ] 居民身份 `uncertain` 时不得输出「最终应补税额」单点值
